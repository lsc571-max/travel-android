# 여행 통역 — 안드로이드 앱

웹 통역 앱(M28)의 기능을 그대로 옮긴 안드로이드 앱입니다. 번역은 **폰 안 오픈소스 AI(Hy-MT2)** 가 기본이고,
무료 번역기(인터넷)와 Gemini도 고를 수 있습니다.

## 설치 파일 받기
1. 이 저장소에 파일을 올리면(push) GitHub가 자동으로 설치 파일을 만듭니다. (처음 약 15분, 다음부터 3~4분)
2. 저장소 → 오른쪽 **Releases** → **여행 통역 앱 (최신)** → `travel-interpreter.apk` 를 눌러 받습니다.
3. 받은 파일을 눌러 설치합니다. ("출처를 알 수 없는 앱" 허용이 필요합니다)

## 처음 켰을 때
- "폰 안 번역 AI를 받을까요?" 가 나오면 **지금 받기** (약 1.1GB, 와이파이 권장).
- 다 받으면 자동으로 기본 번역기가 됩니다. 그 전에는 무료 번역기로 동작합니다.
- 설정 → **번역 AI** 탭에서 번역기 고르기, 모델 받기·지우기·바꾸기, 음성 인식 방식을 정합니다.

## 구성
| 위치 | 내용 |
|---|---|
| `app/src/main/assets/index.html` | 화면과 통역 기능 (웹 앱 정리본) |
| `app/src/main/assets/native.js` | 화면 ↔ 휴대폰 기능 연결 (음성 인식·목소리·폰 AI·공유·파일 저장) |
| `app/src/main/java/kr/pureun/travel/` | 안드로이드 쪽 코드 |
| `.github/workflows/build.yml` | 설치 파일 자동 만들기 |
| `keystore/debug.keystore` | 서명 키 (항상 같은 키라서 덮어 설치 가능) |

## 쓰는 오픈소스
- 번역 모델: Tencent Hy-MT2-1.8B (Apache-2.0) — 앱에서 처음 한 번 내려받음
- 번역 엔진: llama.cpp (MIT) — 설치 파일을 만들 때 함께 빌드
